# punchurl

Punch encode/decode helpers for url payloads in pipelines.

**Site:** https://theworker02.github.io/punchurl/

## Install / run

```bash
git clone https://github.com/theworker02/punchurl.git
cd punchurl
node src/cli.js
node --test
```
